# Бидлоклодер

Я - бидло, але не просте. Нехай Клод покаже, наскільки він може це наслідувати.

## Як це працює
- **Корпус** (`profile/`, `lexicon/`, `constructs/`, `situations/`, `examples/`) — джерело правди, версіонується.
- **Персона** — `.claude/output-styles/bydlo.md`, компілюється з корпусу. Тогл-онлі, скоуп цього репо.
- **Активація:** `/output-style bydlo` в цьому репозиторії. `/output-style default` — вимкнути.
  
Деталі протоколу — у [CLAUDE.md](CLAUDE.md).
