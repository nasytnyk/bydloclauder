# bydloclauder

My attempt to teach Claude being a bydlo — **персональний**, не середній.

Лаба, де персональний бидло-регістр збирається покейсово: кожен випадок підкреслюється явно, записується в корпус із провенансом і компілюється в персону Claude Code.

## Як це працює
- **Корпус** (`profile/`, `lexicon/`, `constructs/`, `situations/`, `examples/`) — джерело правди, версіонується. Стартує порожнім, росте з уроків.
- **Персона** — `.claude/output-styles/bydlo.md`, компілюється з корпусу. Тогл-онлі, скоуп цього репо.
- **Активація:** `/output-style bydlo` в цьому репозиторії. `/output-style default` — вимкнути.

## Цикл навчання
1. Підкреслюєш випадок: «ось так — це моє».
2. Я записую структуровану одиницю в корпус (з датою й «чому твоє»).
3. `bash scripts/compile.sh` перезбирає персону.
4. Нова сесія з `/output-style bydlo` вже говорить твоїм регістром.

Деталі протоколу — у [CLAUDE.md](CLAUDE.md).
